# Информационная система охранного агентства

Курсовая работа Иманкулова С. А., вариант 27. Приложение для Windows на C# и WPF ведёт учёт сотрудников, клиентов, договоров, платежей, снаряжения и дежурств.

## Запуск

Нужны Windows и .NET 9 SDK. Откройте терминал в папке с `Kursc.csproj` и выполните:

```powershell
dotnet build
dotnet run
```

В Visual Studio можно открыть `Kursc.csproj` и запустить проект клавишей F5.

## Возможности

- **Сотрудники** — добавление и редактирование карточек, поиск, фильтры по должности и статусу, архив уволенных. Оклад берётся из должности, персональная надбавка задаётся в карточке.
- **Клиенты** — карточки физических и юридических лиц.
- **Договоры** — охрана мероприятий для физических и юридических лиц, охрана объектов для юридических лиц. В карточке доступны состав охраны, платежи и счёт. Завершённые договоры можно отфильтровать.
- **Дежурства** — суточные смены с перерывом не менее двух суток, заполнение графика до даты, переносы и история замен с причинами.
- **Снаряжение** — учёт, выдача и возврат оружия и спецсредств.
- **Отчёты** — список фактических поступлений за выбранный период и итоговая сумма.

Охрана мероприятия оплачивается за часы работы выделенных сотрудников. Для охраны объекта тариф за месяц умножается на число охранников, предусмотренное для всего графика объекта. Неполный месяц рассчитывается пропорционально дням.

## Выходные документы

| Документ | Где открыть |
| --- | --- |
| Финансовый отчёт | **Отчёты** → выбрать период → **Сформировать** |
| Счёт клиенту | **Договоры** → выбрать договор → **Сформировать счёт** |
| График дежурств | **Дежурства** → выбрать объект и при необходимости применить фильтры → **Печать графика** |

Финансовый отчёт и график можно сохранить в PDF через системное окно печати, выбрав **Microsoft Print to PDF**. Счёт открывается в отдельном окне просмотра.

## Структура проекта

| Путь | Назначение |
| --- | --- |
| `Main.cs` | Точка входа приложения |
| `Windows/` | Окна WPF, обработчики событий и общий словарь стилей |
| `Models/` | Сотрудники, клиенты, договоры, дежурства и снаряжение |
| `Storage/` | Модель данных приложения, загрузка и сохранение |
| `Data/data.json` | Демонстрационные и рабочие записи |

Данные сохраняются в текстовом JSON-файле и загружаются при следующем запуске. В архивных карточках выводится дата хранения через пять лет после увольнения или завершения договора. Автоматической очистки архива нет.

## Сценарий для защиты

1. Откройте **Сотрудники**, примените фильтр по должности и переключитесь на архив.
2. В **Договорах** выберите **ОБ-101** и сформируйте счёт. Переключите расчётный период и сравните начисление, оплату и остаток.
3. В **Дежурствах** выберите **ОБ-101**. Найдите смену за **10.11.2026** с заменой и сохраните график в PDF.
4. В **Отчётах** задайте период **01.11.2026–10.11.2026** и сформируйте финансовый отчёт.
5. В **Снаряжении** покажите свободные и закреплённые записи.
